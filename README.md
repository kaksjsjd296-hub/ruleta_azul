# Ruleta Azul (Fabric 1.21.1)

Mod con una **Ruleta Azul** (menu transparente con 8 eventos aleatorios) y un **Temporizador** (boss bar que baja con el tiempo).

## Como obtener el .jar con GitHub
1. Crea un repositorio nuevo en GitHub (por ejemplo `ruletaazul`).
2. Sube TODO el contenido de esta carpeta (incluida la carpeta oculta `.github`).
3. Entra a la pestana **Actions**: se ejecuta solo "Build mod" (tarda 2-4 min).
4. Descarga el `.jar` desde **Releases -> Ruleta Azul (ultima version)** o desde el *Artifact* `ruletaazul-jar` del workflow.
5. Ponlo en `.minecraft/mods` junto con **Fabric API** (1.21.1).

## Uso
- Pestana creativa **Ruleta Azul**: `Ruleta Azul` y `Temporizador`.
- Click derecho con la ruleta: elige un numero (1-8), pon el TIEMPO (ej. `90`, `5m` o `1:30`; vacio = sin limite) y pulsa ACTIVAR / DESACTIVAR.
- Click derecho con el temporizador: minutos, segundos, nombre y color de la boss bar.

## Eventos
1. Terremoto nivel 10  2. Huracan polar  3. Lluvia electrica  4. Incendios forestales
5. Lluvia de meteoritos  6. Niebla mortal  7. Horda zombi  8. Glaciacion
